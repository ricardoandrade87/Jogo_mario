# Jogo_mario

## Descrição
Criação de um jogo simples em HTML, CSS e JavaScript

## Objetivo do projeto
Desenvolver um jogo simples utilizando ferramentas de desenvolvimento web. E aplicar o uso de Git e Github de forma prática

## Tecnologias utilizadas
-HTML

-CSS

-Javascript

## Instalação

### Clone o repositório e acesse a pasta do projeto:

```bash
https://github.com/ricardoandrade87/Jogo_mario.git
cd Jogo_mario
```
## Execução

Entre na pasta frontend e abra o arquivo index.html para iniciar o jogo

## Como Jogar

-Clique em qualquer botão para pular

-Em caso de game-over, reinicie a página para recomeçar
